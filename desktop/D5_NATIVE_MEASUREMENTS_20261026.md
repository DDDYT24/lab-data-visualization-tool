## 原生交互与收尾

真实托盘菜单已在最大化前台窗口下捕获，包含 Open LabViz / Retry startup / Open logs / Exit LabViz。实际点击 Open LabViz 后观察到对应 `window-shown` 事件。菜单由显式验收会话调用 Windows 原生托盘接口弹出；通知区域图标本身的右键命中仍未验证。一次对 Exit LabViz 的坐标输入未取得确定响应，不计通过；同一宿主的原生退出处理器通过验收入口继续验证，不能替代菜单入口命中。

实际 RFD/Windows 对话框验证：取消退出、等待工作完成、取消等待、任务完成后的最终“否”、中断二次确认“否”保留工作，以及二次确认“是”后中断自有合成上传并退出。最终等待完成后选择“是”的分支尚未实际操作。两项原生保护通过：显示窗口取消正在进行的快照/排空；模拟写盘失败保留编辑器与服务并恢复接收。屏幕上的 `Acceptance: disk write failed` 属于这项注入场景。

明确中断后宿主退出0，自有后代无残留，数据库quick_check为ok、无外键问题。中断夹具的MSG_PEEK分支没有及时消费终止连接，原始结果保持 `passed:false`；收尾读取取得预期的 `ConnectionAbortedError(10053)`。`explicit-interruption-assessment.json` 结合原生确认事件、连接中止和创建时间绑定的零残留单独评估中断行为，不覆盖夹具失败记录。
