# LabViz V2.1 / 本地发布候选

> 本文件记录 V2.1 本地发布候选的范围、验证结果和限制。正式 GitHub Release 仍需完成
> 发布检查清单并创建版本标签；实现顺序和勾选状态以 [`TODO.md`](TODO.md#v21-roadmap) 为准。

## 目标

V2.1 继续保持本地优先、无需用户编写 Python 代码的工作流（运行时仍需安装 Python），优先解决结构化 3D 数据被误画成折线图、
网格边界被误报为异常，以及前端预览和后端导出缺少浏览器级一致性验证的问题。完成 P0
后，再推进初学者引导、科研分析能力和最小实验级数据模型。

## 已完成的 P0 范围

- 识别规则矩形网格、重复坐标、缺失网格单元、非有限值和共线点。
- 在 3D 曲面模式中明确选择 X、Y、Z，而不是让用户猜测通用“响应字段”的顺序。
- 对规则网格关闭由行顺序造成的假突变提示，并保留真实突变。
- 用 `07_surface3d.csv` 建立浏览器级回归：441 个曲面点、3D 坐标轴、旋转/缩放和三种导出格式。

## 兼容性进度

- 已使用 Unicode-safe 的 `Content-Disposition` 生成中文文件名清洗下载并复测原始样例。
- 已重新执行 23 份测试数据、API、浏览器和导出矩阵，并记录未配置的测试范围。
- 已修复历史数据库迁移与 SQLAlchemy 元数据之间的检查约束名称漂移，使新建 PostgreSQL
  数据库上的 `alembic check` 干净通过。

## 当前基线与限制

- V2.0 本地自托管核心流程保持不变；AWS Phase 6C/6D 不属于 V2.1 的本地发布门槛。
- `07_surface3d.csv` 的数值、API 和后端 PNG/SVG/PDF 导出已经核对；浏览器 3D 回归使用同等
  21×21 确定性答案键响应验证 441 个点和三种导出请求。它不替代真实外部浏览器、GPU 和
  操作系统组合的兼容性测试。
- BOM 表头和中文下载文件名两个兼容性回归均已关闭，并保留原始样例与自动化回归。
- 私有本地工作簿、真实 SMTP/SES 邮件、AWS、外部 GPU 和操作系统组合未配置，因此不计入
  本地通过证据，也不阻塞本地自托管发布候选。
- 原生桌面安装包、第三方登录、团队协作、计费、移动端高级 3D 和公开云运维继续延期。

## V2.1 完成条件

1. 三个 P0 门槛全部通过，并有答案键 fixture 和浏览器证据。
2. 三个 P1 方向具备实现、API/Schema、双语界面、可复现 fixture 和限制说明。
3. 两个已知兼容性回归关闭，并保留自动化回归测试。
