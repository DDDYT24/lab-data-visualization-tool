## Performance snapshot

`python -m scripts.measure_v22_performance --repetitions 3` produced this processing-only baseline on
Windows 11 / Python 3.12.14 / pandas 3.0.5. Values below are conservative maxima across three runs:

| Case | Load ms | Quality ms | Analysis ms | PNG ms |
| --- | ---: | ---: | ---: | ---: |
| 24 rows | 9.23 | 15.48 | 6.58 | 267.40 |
| 1,000 rows | 2.34 | 17.80 | 20.50 | 321.28 |
| 10,000 rows | 8.48 | 38.03 | 24.21 | 293.68 |
| 21×21 surface | n/a | 117.66 | 173.91 | 793.18 |
| 101×101 surface | n/a | 222.16 | 200.93 | 934.86 |

The maximum whole-case times are 295.39, 383.22, 374.52, 1,084.75, and 1,263.12 ms in the same
order. The current report records a 212.25 MiB process peak across the repeated run. The mock-backed
browser run measured 1,943 ms from sample import to ready, 846 ms to the first chart, and 478 ms
for chart interaction. The versioned budget checker returned `pass` with zero violations;
the budget file is now `status: enforced` for this reference machine. These thresholds are
not a guarantee for every machine. Machine-readable reports are kept under ignored
`outputs/v22-three-gates/`.
