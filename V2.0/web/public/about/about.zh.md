LabViz 通过清晰的本地工作流程，将实验数据表转换为图表。它面向希望检查数据、制作适合发表的图表，但不想编写绘图代码的用户。

## 产品优势

- 支持导入 CSV、TSV/TXT、JSON 和 Excel 工作簿；绘图前可检查工作表、列、识别出的类型和数据质量提示。
- 清洗决定会在项目流程中明确显示，不会悄悄改动可疑数据。
- 可创建常见二维图表和有效网格上的 X/Y/Z 曲面；选定方法支持时可使用拟合和不确定性选项。
- 支持导出 PNG、SVG、PDF，并将图表快照保存在本地项目历史中。
- 无需在线账号即可使用：真实导入的项目和图表快照保存在当前电脑用户的本地配置目录。

## 适用人群

LabViz 面向学生、实验室研究人员、教师及需要从实验测量表格制作图表的研究团队。适合在同一流程中完成数据检查、质量审阅、绘图和可复现导出。

## 本地存储与隐私

LabViz 的网页界面和数据处理 API 都在当前电脑运行。普通本地流程不需要登录、邮件服务、云存储或互联网。原始上传文件不会作为原文件附件保留；处理后的项目数据和元数据会保存在 LabViz 本地配置目录。图表快照会保留在本机，直到你删除快照或项目。重新安装或换电脑前，请先备份 LabViz 本地数据目录。

## 当前限制

LabViz V2.2.0 是面向单个普通 Windows 用户的本地发布版；双账户隔离未验证，云协作仍延期。它不提供跨设备同步、公开分享、团队账号或 Google/Microsoft 登录。质量提示需要用户判断，不能替代科学结论。统计工具各有适用假设；3D 曲面需要合适且完整的规则网格。发表前请检查诊断结果和最终导出图。
