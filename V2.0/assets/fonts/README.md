# Bundled export font

NotoSansSC-VF.ttf is the unmodified Noto Sans SC variable font from
https://github.com/google/fonts/tree/main/ofl/notosanssc (retrieved 2026-09-13).

SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`.

Redistribution is covered by the accompanying OFL.txt. Preserve that notice in
packages. LabViz loads this private application font without installing a system
font. SVG exports embed a glyph subset while retaining text; PDF embeds TrueType
font data and a Unicode map. The original font is retained here unchanged.
